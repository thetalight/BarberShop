# ST001 production outline — v4 dialogue and learning

剧情与对白的唯一来源：`../../series/xiangwei/stories.jsonl` 中 `ST001`。镜头时间由 `build_composition.py` 根据 `assets/voice/manifest.json` 生成到 `timing.json`；此文件只说明画面执行。

| 时间 | 画面执行 | 连续性重点 |
| --- | --- | --- |
| 0–2.883 s | 开场立即听到约会悬念。店内宽景交代爸爸、米勒爷爷和玩具角女儿，随后切米勒近景。 | 女儿从开场就在窗边玩具角。 |
| 2.883–7.761 s | 爸爸近景追问，米勒低头看手机坦白；给爸爸听后的惊讶反应。 | 顾客手机始终由同一人持有。 |
| 7.761–12.395 s | 爸爸惊讶近景，切米勒紧张的表情。 | 用硬切区分说话和倾听，不让不同姿势交叠。 |
| 12.395–15.599 s | 爸爸近景示范邀请句，米勒决定拿起手机。 | 核心表达首次用于具体情境。 |
| 15.599–21.475 s | 米勒右手持手机靠右耳；女儿仍从原玩具角探头等待答复。 | 电话不换手；女儿不凭空出现或消失。 |
| 21.475–25.967 s | 米勒放下电话转述；爸爸指向理发椅并打开围布，米勒转身准备坐下。 | 语言中的“得快点”落实为动作。 |
| 25.967–34.967 s | 前 4.75 秒是原句双语跟读，后 4.25 秒切换到咖啡变体；每句配音后留开口时间。 | 学习卡和双语字幕来自同一 JSONL 与声音时间轴。 |

七段画面均由生成脚本写入 `compositions/scene-*.html`，含姿势切换和缓慢机位运动；人物状态变化使用硬切。没有口型同步。正式交付前按 `skills/barber-video-qa/SKILL.md` 检查工程及导出的 MP4。
