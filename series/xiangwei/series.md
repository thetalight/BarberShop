# 老爸的英语理发店 · 日更英语情景剧设定

**定位：一家理发店，每天一段生活英语。** 中国爸爸在美国社区经营一间长期营业的小理发店。四岁的女儿放学后常待在店内玩具角，几位熟客与邻店老板持续出现。每天围绕一件小事展开英语对话，让观众学会一个可直接使用的生活表达。

## 固定人物与空间

| 角色 | 不变的性格与用途 |
| --- | --- |
| 爸爸 `human_barber_v1` | 约 38 岁，手艺好、温和，英语能正常接待和闲聊；偶尔因噪音或俚语请求确认，不承担每集翻译员的工作。米色衬衫、深棕围裙。 |
| 女儿 `daughter_v1` | 四岁，齐肩深色短发，绿色花朵发夹，绿色上衣、卡其背带裤。生活在中英双语家庭，在幼儿园接触英语。只说符合年龄的短句、问具体问题；并非每集参与主对话。固定在玩具角活动。 |
| 上班族熟客 `commuter_regular_v1` | 经常下班后来，关心工作、通勤、午饭和周末，有时赶时间。 |
| 退休熟客 `retired_regular_v1` | 有时间聊天，喜欢钓鱼、照顾花草，养一只叫米洛的狗。 |
| 邻店老板 `neighbor_owner_v1` | 经营隔壁咖啡店，偶尔送饮品、借东西或帮忙修店里的小问题。 |

常驻店内场景是美国社区街角的理发店：一把主要理发椅、圆镜、暖灯、木柜，以及女儿的固定玩具角。新剧集使用 `series/xiangwei/assets/fixed.json` 里的 `US_*` 场景和上述固定人物参考图。顾客以固定熟客为主；偶尔出现的新顾客才新增单集参考图。剧情不要求每集剪发，也不要求剪前剪后外形变化。

固定配音设定保存在 `series/xiangwei/voices.json`。女儿的英文旁白使用本地 Kokoro `af_heart`，语速 0.95、音高系数 1.22；后续由女儿说话的剧集沿用同一音色。

店内玩具角固定在街窗旁；从门口斜拍理发椅时位于画面左侧，其他机位按真实房间方位呈现。女儿在场的剧集从开场建立她的位置：她可以安静玩耍，不必每镜说话；需要加入对话时，先用抬头、起身或走近的动作交代位移。宽镜头再次拍到玩具角时，确认她仍在对应位置；近景裁切导致不入画不等于离开店铺。道具和背景参考图与人物参考图一起复用。

## 日更结构

1. 前 3 秒进入对话或问题，不以长空镜开场。
2. 中间约 25～40 秒，用 6～10 句英语台词解决一件小事。爸爸、顾客和女儿的语言能力符合各自设定。
3. 核心表达在情境里自然出现两次，最多补一个简单变体。笑点或人物回应负责收尾。
4. 最后 3～5 秒显示核心英语、中文意思，并留一次跟读停顿。所有旁白与对话使用英语；字幕同时显示英文原文和中文翻译。爸爸不逐句翻译。

初期目标时长为 40～60 秒。每 10 条选题按 **3 条理发接待与服务、4 条顾客闲聊、3 条父女或邻里互动** 轮换，**9 条店内、1 条附近社区**。开放日可以偶尔出现，不是整季主线。

## 全局故事档案与连续性

`series/xiangwei/stories.jsonl` 是全部故事文字的唯一来源。`ST000` 是已制作的系列开场，保存英语旁白和逐段中文翻译。日更记录使用 `format: "daily_english"`，保存 10～20 字简介、店内小事件、角色、类别、场景、核心表达与中文意思、简单变体、开头与收尾，以及 `continuity_in` / `continuity_out`。`ST001` 已制作；`ST002`～`ST030` 是待写对话的选题。

连续性依靠小细节：熟客提过的钓鱼之行可以几集后被问起；女儿的画贴在玩具角；坏门铃之后被邻店老板修好。每集独立可懂，同时承接记录中已发生的事。写新剧本前先查重核心事件与核心英语表达，再查看角色最近发生的事和店内新增物件。

当日更选题进入 `scripted` 或 `produced`，记录须补 6～10 句 `dialogue`；每句含 `speaker`、`en`、`zh`。系列开场已采用英语配音和双语字幕；日更故事中的多角色音色、口型与跟读停顿仍需在首次对话篇中实测。
