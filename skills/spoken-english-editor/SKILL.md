# 口语教学编辑

检查 `series/xiangwei/stories.jsonl` 中目标故事，并与前几集的 `core_expression`、事件和角色语言能力对照。保持全片英语口播、英文在上的双语字幕；中文只帮助理解，不让爸爸逐句翻译。爸爸英语能正常经营；四岁女儿只用符合年龄的短句。

## 交付标准

- 台词像熟悉的美国社区人物会说的话，意思在情境中成立。优先简短、常用表达，避免为了展示语法而变正式。
- 一集教透一句 `core_expression`：在故事中示范、由人物实际使用，结尾给观众一次跟读；至多加一个只替换少量词的 `variant`，同时给出准确中文。
- 根据实际配音文件而非字数猜测镜头时间；检查开头及信息密集句的词速和句间停顿。面向初学者时，优先删短句子或增加自然反应，避免机械放慢全部对白。
- 双语字幕逐句对齐音频；学习卡须给足读、说和换词的时间。若没有听辨音频，只能报告时长和音轨结构，不能评价发音或音色。

正例：`Who's it with?` 用于熟客间追问；`How about dinner tonight?` 在邀请时说一次，结尾换成 `How about coffee tomorrow?`。反例：熟客聊天中突然用正式的 `With whom?`；一句对白塞入多个新表达；配音改了却沿用旧字幕时间。
